# Conway's Game of Life (Rust)

一个基于 Rust 构建的高性能、多线程、无限网格康威生命游戏（Conway's Game of Life）桌面模拟器。

底层采用稀疏哈希集合实现无限演化空间，并通过 `crossbeam` 与 `egui/eframe` 将后台演化计算与前台 GUI 渲染完全解耦，零额外重型引擎依赖。

## 核心特性

* **无限稀疏世界**：基于 `HashSet<(isize, isize)>` 与反向邻域计数，支持向任意正负坐标无限延伸，计算复杂度仅与当前存活细胞数量相关。
* **多线程无锁渲染**：后台独立线程按精确节拍推演，通过 `Arc` 不可变快照与有界通道向主线程推送画面，确保高并发计算下窗口依然保持 60 FPS 流畅交互。
* **自由画布与对称笔刷**：支持以鼠标为锚点的无级缩放、自由拖拽平移、连续绘制/擦除，以及单轴/四象限对称绘制模式。
* **时间旅行与多规则引擎**：内置历史状态环形栈支持单步前进与时空倒流；采用位掩码（Bitmask）实现多种经典 Life-like 元胞自动机规则的实时热切换。
* **完整 RLE 图样生态**：内置标准 RLE（Run Length Encoded）双向编解码器，支持内置预设印章、旋转/镜像预览、区域框选复制、本地 `.rle` 文件拖拽导入及一键导出保存。

## 项目结构

```text
src/
├── lib.rs        # 库入口，公开模拟、图样、快捷键与 GUI 模块
├── main.rs       # 程序入口与跨线程通道编排
├── universe.rs   # 核心演化规则、稀疏网格存储与快照生成
├── sim.rs        # 后台模拟引擎、节拍调度与历史回退栈
├── pattern.rs    # RLE 双向编解码器、几何变换与预设图样库
├── keymap.rs     # 快捷键注册、分发与 F5 帮助生成
└── gui.rs        # egui/eframe 渲染、无限相机变换与输入状态机
```

## 快速开始

确保本地已安装 Rust 工具链（`cargo`），在项目根目录执行：

```bash
cargo run --release
```

*(建议使用 `--release` 模式运行以获得最佳的哈希计算与渲染性能。)*

## 操作指南

### 基础与时间控制

| 按键 / 操作 | 功能 |
| :--- | :--- |
| `Space` | 暂停 / 继续演化 |
| `N` / `→` | 暂停并单步推演下一代 |
| `Z` / `←` | 暂停并回退至上一代（最多支持 200 步） |
| `+` (`=`) / `↑` | 加快演化速度（最高 200 TPS） |
| `-` / `↓` | 减慢演化速度（最低 1 TPS） |
| `C` | 清空当前画布 |
| `Esc` | 关闭帮助窗口；未打开帮助时退出程序 |
| `F5` | 打开 / 关闭快捷键帮助窗口 |

### 画布与创作工具

| 按键 / 操作 | 功能 |
| :--- | :--- |
| **鼠标左键点击 / 拖动** | 绘制或擦除细胞（根据起始格状态自动切换笔刷） |
| **鼠标右键 / 中键拖动** | 平移无限画布 |
| **鼠标滚轮** | 以光标为中心放大 / 缩小网格 |
| `Home` | 重置视角回到世界原点 `(0, 0)` |
| `M` | 切换对称绘制模式（`Off` / `Mirror-X` 左右镜像 / `Quad-XY` 四象限对称） |
| `G` | 在当前屏幕中心生成 $32 \times 32$ 随机汤（Random Soup） |
| `Ctrl + 鼠标左键拖动` | 框选画布中的任意矩形区域 |
| `Ctrl + C` | 将框选区域内的活细胞提取为图样印章 |
| `Ctrl + S` | 将框选区域（若无框选则导出整个世界）保存为时间戳 `.rle` 文件 |

### 图样印章与 RLE 导入

| 按键 / 操作 | 功能 |
| :--- | :--- |
| `1` ~ `5` | 选择内置预设图样（滑翔机、轻量级飞船、脉冲星、十五连珠、滑翔机枪） |
| **拖入 `.rle` 文件** | 从系统文件管理器直接拖拽 `.rle` 文件到窗口加载图样 |
| `R` / `F` | 预览状态下顺时针旋转 90° / 水平镜像翻转 |
| **左键点击** (`Shift + 左键`) | 放置图样（按住 `Shift` 可连续盖章） |
| **鼠标右键** / `Backspace` | 取消当前图样预览或清除框选区域 |

### 规则切换

| 按键 | 规则名称 | 规则记号 |
| :--- | :--- | :--- |
| `F1` | Conway's Life（默认） | `B3/S23` |
| `F2` | HighLife | `B36/S23` |
| `F3` | Seeds | `B2/S` |
| `F4` | Day & Night | `B3678/S34678` |
